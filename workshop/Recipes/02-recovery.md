# Recovery

Read the first Python traceback in Output Log. Preserve your log and project before changing anything. The builder refuses an existing map to protect your work. A failed build may have created a partial map. Use a clean Starter copy for a retry, or open and inspect an already completed map. Never delete an accepted map merely to rerun a demo.

Unreal Python is editor-only. The generated maps, materials and LevelSequence are native assets that remain after Python finishes.
